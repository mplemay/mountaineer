# Deploy

You can deploy your Mountaineer project on any host that can run Python.
Mountaineer does not require Docker or containerization.
This page documents a simple host-based deployment workflow using `uv`.

## Requirements

- Python 3.11 or higher
- Node.js 18 or higher (only if you use the PostCSS builder plugin)
- `uv` for dependency management

## Build and Run

Use `uv` to install dependencies, build frontend assets, and run uvicorn.

```bash
uv venv
uv sync --frozen --no-dev
uv run build
ENVIRONMENT=PRODUCTION uv run uvicorn my_webapp.main:app --host 0.0.0.0 --port 3000
```

`uv run build` compiles your frontend assets and SSR bundles.
The `ENVIRONMENT=PRODUCTION` flag ensures production-minified assets are served.

## Local Testing

To verify your production setup locally, run the same build and uvicorn command.

```bash
uv run build
ENVIRONMENT=PRODUCTION uv run uvicorn my_webapp.main:app --host 127.0.0.1 --port 5006
```

## Process Management (Optional)

For long-running services, use a process manager like systemd or supervisor.
Configure it to run the uvicorn command above and to restart on failure.

## Common Errors

If `uv run build` fails, verify that Node.js is available when using PostCSS.
If uvicorn fails to import your app, verify the module path matches your `main.py`.
